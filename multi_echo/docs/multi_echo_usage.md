# Multi Echo Candy 使用说明

## 功能简介

机器人收到以下格式的消息时，机器人会自动发送`@发送者 费用`，每种格式对应独立的商品目录。

| 消息格式                                     | 匹配的商品目录                      | 示例                                     |
|----------------------------------------------|-------------------------------------|------------------------------------------|
| `收2/代号/费用` 或 `收代号/费用`             | `设置压车数` 设置的目录             | `收2/123/100` 或 `收123/100`             |
| `收2/代号/费用一包杀` 或 `收代号/费用一包杀` | `设置一包杀压车数` 设置的目录       | `收2/123/100一包杀` 或 `收123/100一包杀` |
| `拼随机三尾三包 代号/费用`                   | `设置随机三尾三包压车数` 设置的目录 | `拼随机三尾三包 123/100`                 |

每个机器人账号拥有独立的商品列表、群登记记录，延迟设置按群维度独立存储。

> 💡 商品代号按集合进行比较，因此 `123` 与 `321` 视为同一代号。  
> 💡 当消息费用超过商品费用上限时，机器人会以上限进行回复，而小于下限时忽略该消息。  
> 💡 `收` 与 `收2` 前缀均允许中间或后面带有空格，如 `收 2/123/200`、`收 123/200`、`收 123/200一包杀` 同样可以被识别。  
> 💡 开启随机回复后，所有机器人对同一条消息的随机扣减数字保持一致。

---

## 开始流程

```text
1. 添加主人 123456789                   ← 添加管理员（超级管理员操作，可选）
2. 添加群 1234567890                   ← 将群登记并启用
3. 切换总开关                           ← 确认总开关已开启（仅首个连接的机器人生效）
4. 设置压车数 <123-200/456-400/...>   ← 设置商品目录
5. 设置下限 <群号>#<费用>               ← 设置该群商品费用下限
6. 收2/123/200                        → 机器人 "@发送者 200"
7. 拼随机三尾三包 123/200                → 机器人 "@发送者 200"
```

> 💡 可随时用 `@机器人 查看状态` 查看当前配置。

## 权限说明

| 角色       | 来源                                                             | 能做什么                             |
|------------|------------------------------------------------------------------|--------------------------------------|
| 超级管理员 | `.env.multi_echo_candy` 中 `SUPERUSER` 配置的 QQ 号 / 机器人自身 | 全部权限，包括管理管理员             |
| 管理员     | 由超级管理员通过命令添加                                         | 群管理、跟随管理、查看状态、设置延迟 |

## 命令一览

### 管理员管理（仅超级管理员）

> 📌 在群内发送时，对该群内 **所有在线的机器人**生效。

| 命令              | 说明       |
|-------------------|------------|
| `添加主人 <QQ号>` | 添加管理员 |
| `删除主人 <QQ号>` | 删除管理员 |

### 屏蔽用户管理（仅超级管理员）

| 命令                | 说明                                 |
|---------------------|--------------------------------------|
| `添加屏蔽人 <QQ号>` | 屏蔽用户，被屏蔽用户的消息不再被复读 |
| `删除屏蔽人 <QQ号>` | 取消屏蔽用户                         |

### 群管理

> 📌 在群内发送时，对该群内 **所有在线的机器人**生效。

| 命令            | 说明                 |
|-----------------|----------------------|
| `添加群 <群号>` | 将群登记并启用       |
| `删除群 <群号>` | 将群停用（保留记录） |

### 商品管理

> 📌 在群内发送时，对该群内 **所有在线的机器人**生效。

| 命令                                                       | 说明                                                                |
|------------------------------------------------------------|---------------------------------------------------------------------|
| `设置压车数 <代号-费用上限/代号-费用上限/...>`             | 设置商品目录（`收2` 或 `收` 触发）                                  |
| `删除压车数 <代号-费用上限/代号-费用上限/...>`             | 删除商品目录                                                        |
| `设置随机三尾三包压车数 <代号-费用上限/代号-费用上限/...>` | 设置随机三尾三包商品目录（`拼随机三尾三包` 触发）                   |
| `删除随机三尾三包压车数 <代号-费用上限/代号-费用上限/...>` | 删除随机三尾三包商品目录                                            |
| `设置一包杀压车数 <代号-费用上限/代号-费用上限/...>`       | 设置一包杀商品目录（`收2/代号/费用一包杀` 或 `收代号/费用一包杀` 触发） |
| `删除一包杀压车数 <代号-费用上限/代号-费用上限/...>`       | 删除一包杀商品目录                                                  |
| `设置下限 <群号>#<费用>`                                   | 设置该群商品费用下限                                                |
| `清空商品`                                                 | 删除当前机器人的所有商品记录                                        |

### 开关与状态

| 命令                 | 说明                                          |
|----------------------|-----------------------------------------------|
| `切换总开关`         | 开启 / 关闭全局功能（仅首个连接的机器人生效） |
| `@机器人 查看状态`   | 查看在线账号、本群开启状态                    |
| `@机器人 查看群列表` | 查看群登记列表                                |

### 延迟设置

| 命令                           | 说明                              |
|--------------------------------|-----------------------------------|
| `设置群延迟 <群号>#<延迟毫秒>` | 设置指定群的回复延迟（0~30000ms） |

### 随机回复与压车符号设置

| 命令                            | 说明                                                              |
|---------------------------------|-------------------------------------------------------------------|
| `设置群随机回复<QQ群号>#<数字>` | 设置指定群的随机回复扣减上限，回复时会随机减去 0 到该数字之间的值 |
| `切换随机回复群开关<群号>`      | 开启 / 关闭指定群的随机回复功能，不开启则正常回复                 |
| `开启群压车符号 <群号>`         | 开启指定群的压车符号功能，开启后回复费用末尾会带有随机符号        |
| `关闭群压车符号 <群号>`         | 关闭指定群的压车符号功能                                          |

> 💡 随机回复开启后，机器人回复的费用 = 原费用 - 随机值（不低于商品下限）。  
> 💡 所有机器人对同一条消息使用相同的随机种子，因此扣减的数字保持一致。
> 💡 压车符号开启后，机器人回复费用后面会追加随机符号（符号池：`%`、`(`、`-`、`.`、`,`、`#`、`!`、`*`、`+`）。

## 消息发送条件

以下条件 **全部满足** 时，机器人才会回复：

1. ✅ 总开关已开启
2. ✅ 当前群已登记且处于启用状态
3. ✅ 发送者未被屏蔽
4. ✅ 消息格式符合以下任一规则：
   - 普通压车：`收2/代号/费用` 或 `收代号/费用`（如 `收2/123/100`、`收123/100`）
   - 一包杀：`收2/代号/费用一包杀` 或 `收代号/费用一包杀`（如 `收2/123/100一包杀`、`收123/100一包杀`）
   - 拼随机三尾三包：`拼随机三尾三包 代号/费用`（如 `拼随机三尾三包 123/100`）
5. ✅ 代号在对应的商品目录中存在（匹配时比较消息字符串和数据库字符串是否为同一集合，如 `123` 与 `321` 视为同一代号）
6. ✅ 费用 ≥ 该群的商品费用下限
7. 💡 若费用 > 商品费用上限，则以上限值回复
8. 💡 若该群开启了随机回复，则回复费用会随机减少（不低于商品下限），且所有机器人扣减数字一致
9. 💡 若该群开启了压车符号，则回复费用后会追加随机符号

## 常见问题

| 问题                             | 原因                                                                                     |
|----------------------------------|------------------------------------------------------------------------------------------|
| 发了收车指令没反应？             | 检查消息格式是否正确（需由斜杠隔开），并确认代号已在对应商品目录中                       |
| 群登记了但不复读？               | 检查该群是否已启用，以及总开关是否开启                                                   |
| 换了个机器人号就不工作了？       | 群登记记录、商品列表是**按机器人账号独立存储**的，检查设置商品时该机器人是否在群并且在线 |
| QQ号/群号提示不合法？            | 号码需为 6~13 位数字且不以 0 开头                                                        |
| 重复添加/删除会怎样？            | 正常返回成功/取消提示，不会报错                                                          |
| 设置了随机回复但不生效？         | 需要先用 `切换随机回复群开关<群号>` 开启该群的随机回复开关                               |
| 多个机器人随机扣减的数字不一样？ | 正常情况下不会出现，系统使用消息时间戳作为随机种子保证一致性                             |
| `拼随机三尾三包` 消息没反应？    | 检查是否使用 `设置随机三尾三包压车数` 设置了对应的商品目录（与普通商品目录独立）         |
